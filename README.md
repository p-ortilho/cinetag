# 🎬 Cinetag

Esse é um projeto desenvolvido durante o curso de React: praticando React com Js React. Durante as aulas foram abordados diversos temas, como:

- 📦 Criação de componentes
- 🌐 Mockagem de API
- ⚛️ Uso e criação de hooks para o React
- 🎨 Estilização com CSS
- 🛣️ Criação de rotas com react-router-dom
- 🔄 Renderização de componentes de forma dinâmica

## 🚀 Instalação

1. Copie o repositorio localmente:
~~~ 
git clone git@github.com:p-ortilho/cinetag.git
~~~

2. Instalando as dependencias 
~~~
npm install
~~~

2. Rodando o projeto
~~~
npm start
~~~
